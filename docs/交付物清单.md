打 ZIP 前删除或排除：

- `server/.venv/`、`server/.venv312/`、`**/__pycache__/`、`**/.pytest_cache/`
- `apps/desktop/node_modules/`、`apps/desktop/release/` 中的中间产物可按体积取舍，**最终安装包**应保留在 `release/`
- `server/.env`、真实 API Key、含会话数据的 `~/.personal-super-assistant/assistant.db`
- IDE / OS 垃圾：`.DS_Store`、`Thumbs.db`

## 3. 必做 / 进阶 / 创新对照（功能验收）

| 层级 | 赛题原文 | 本作品落地 |
