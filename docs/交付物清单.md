## 2. 构建产物（当前本机进度）

目标平台：Windows x64 · macOS Intel (x64) · macOS ARM (arm64)。请在**对应架构真机**分别构建 sidecar，再打 Electron 包。

| 平台 | sidecar | 安装包建议放入 `release/` |
|------|---------|---------------------------|
| macOS ARM | `resources/sidecars/darwin-arm64/server-darwin-arm64` | `PersonalSuperAssistant-1.0.0-arm64.dmg`（及可选 zip） |
| macOS Intel | `resources/sidecars/darwin-x64/server-darwin-x64` | `PersonalSuperAssistant-1.0.0.dmg` / 带 x64 后缀 |
| Windows x64 | `resources/sidecars/win32-x64/server-win-x64.exe` | `PersonalSuperAssistant Setup 1.0.0.exe` |

本机（Apple Silicon）已具备：

- sidecar：`resources/sidecars/darwin-arm64/server-darwin-arm64`
- 安装包：`apps/desktop/release/PersonalSuperAssistant-1.0.0-arm64.dmg`（约 144MB）  
  打 ZIP 前请拷贝到压缩包内的 `release/mac-arm64/`（不要把整个 `apps/desktop/release` 中间产物原样塞进交付包）。

其余架构在对应机器执行：

```bash
# macOS / Linux
./scripts/build-sidecar.sh && ./scripts/build-desktop.sh

# Windows（cmd）
scripts\build-sidecar.cmd
scripts\build-desktop.cmd
```

预置模型（空库首次启动写入）：`server/app/llm/presets.py` 中的 qwen3.8-max（阿里云百炼兼容端点）。评委也可在设置页自行改 Profile。

### 打包前务必排除

- `server/.venv/`、`server/.venv312/`、`**/__pycache__/`、`**/.pytest_cache/`
- `apps/desktop/node_modules/`、`apps/desktop/release/`（中间目录与 `.blockmap`、`mac-arm64/` 解压树）；**只保留**拷到根级 `release/` 的最终 dmg/exe/zip

- IDE / OS 垃圾：`.DS_Store`、`Thumbs.db`、`docs/.~*.docx` 等 Word 锁文件

> 说明：预置模型密钥写在 `server/app/llm/presets.py` 以便演示开箱可用；这与「不要把开发态 `.env` / 用户库打进 ZIP」不冲突。若赛题要求交付包零密钥，提交前可清空 presets 中的 `api_key` 并在说明中写明评委自备 Key。

## 4. 功能覆盖一览（验收对照）

| 能力层 | 要点 | 落地 |
|--------|------|------|
| 基础 | 环境可跑、LLM 可配、文件白名单、内置技能 | `install.sh`；设置 → 模型；打开文件夹写白名单；`skills/` + 插件市场试运行 |
| 拓展 | 技能 / 记忆 / MCP / 办公 IM / 对话体验 | 渐进技能与斜杠；对话内记忆；预置连接器；飞书工具 + 企微等 MCP；SSE、确认闸、思考区、联网搜索 |

| 工程约束 | 安全与分层 | `contextIsolation`；LLM 仅后端；IPC 白名单；路径白名单；密钥脱敏 |
