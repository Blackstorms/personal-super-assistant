# 数据库配置说明

本系统使用**单机 SQLite**，无独立数据库账号密码。访问控制依赖本机登录换取的 Bearer Token，且 FastAPI 仅监听 `127.0.0.1`。评委只需保证 `resources/db/schema.sql` 随源码提交，应用启动即会建表。

## 基本信息

| 项 | 值 |
|----|----|
| 数据库类型 | SQLite 3（需 FTS5） |
| 驱动 | Python `aiosqlite` |
| 默认库文件 | `~/.personal-super-assistant/assistant.db` |
| 数据目录覆盖 | 环境变量 `PSA_DATA_DIR` |
| 结构脚本 | `resources/db/schema.sql`（权威 DDL） |
| 可选种子 | `resources/db/seed.sql`（占位；预置专家/MCP/技能由启动逻辑 `INSERT OR IGNORE`） |
| 适配系统 | Windows x64、macOS Intel、macOS ARM |

字符集 UTF-8；主键均为 UUID 文本；时间戳 ISO8601 UTC 文本；JSON 字段以 `TEXT` 存储。

## 初始化步骤

1. **推荐**：安装依赖后首次启动 FastAPI（`uvicorn` 或 sidecar）。`init_db()` 会执行 `schema.sql`，再跑增量 `migrate_schema`（补列、`user_version`），并写入默认 `llm` / `llm_profiles` / `local_token` / `compress`。预置专家、MCP 连接器在此时插入且不覆盖用户已改配置。  
2. **手工初始化**（仅排障）：

```bash
mkdir -p ~/.personal-super-assistant
sqlite3 ~/.personal-super-assistant/assistant.db < resources/db/schema.sql
```

3. `scripts/install.sh` / `install.ps1` 会断言 `schema.sql` 存在，但不直接导入用户家目录；真正建表发生在进程启动。

## 表与实体对应

| 表 | 业务实体 |
|----|----------|
| app_settings | 应用 KV（LLM、token、压缩阈值、调度、Hermes 错误） |
| llm_profiles | 多模型配置（名称 / base_url / model / 默认标记 / 密钥） |
| whitelist_roots | 文件白名单根目录 |
| workspaces | 项目或本地文件夹空间（指令、专家/技能/MCP/资料库绑定） |
| experts | 专家人设 |
| sessions | 会话（含 `summary_text` / `summary_upto_id` 长上下文摘要） |
| session_attachments | 对话附件元数据 |
| messages | 消息（含 `reasoning_content`、工具调用 JSON） |
| chat_runs | 一次生成运行（停止 / 确认闸 pending） |
| skills | 技能注册态（含 Hermes 扩展列） |
| skill_bundles / pending_skill_writes | 技能组合与待审批写入 |
| hermes_toolset_settings | Hermes toolset 启停 |
| mcp_servers / mcp_tools_cache | MCP 服务与 Discover 缓存 |
| memories / memories_fts | 记忆及全文检索 |
| knowledge_bases | 知识库容器 |
| knowledge_sources / knowledge_documents / knowledge_chunks / knowledge_chunks_fts | 索引源、文档、切片 |
| tool_call_audits | 工具调用审计（I6） |
| checklists / checklist_items | 任务清单（I11） |
| scheduled_jobs / scheduled_job_runs | 定时任务定义与运行历史 |

字段级设计以 `resources/db/schema.sql` 为准。知识原文仍在用户文件系统，库内只存切片与哈希。

## Hermes 运行时数据（不入库）

| 项 | 值 |
|----|-----|
| 源码 | `third_party/hermes-agent/`（MIT，见仓库根 `THIRD_PARTY_NOTICES.md`） |
| HOME | `{PSA_DATA_DIR}/hermes_home`（后端自动创建） |

Skills / MCP 增强走 vendored Hermes；SQLite 只存 PSA 侧配置与缓存。

## 配置参数

| 变量 / Key | 说明 |
|------------|------|
| `PSA_DATA_DIR` | 数据目录 |
| `PSA_HOST` / `PSA_PORT` | 默认 `127.0.0.1:18765` |
| `PSA_ADMIN_USERNAME` / `PSA_ADMIN_PASSWORD` | 登录账号，默认 `admin` / `admin` |
| `app_settings.llm` | 兼容旧版单模型；密钥勿打日志、勿提交 Git |
| `app_settings.compress` | `max_messages` / `max_tokens` / `keep_messages` / `llm_summary` |
| `app_settings.scheduler` | 可选：`enabled` / `poll_interval_seconds` / `max_concurrent_jobs` |

官方 `mcp` Python SDK 需要 **Python ≥ 3.10**。更低版本可跳过该依赖，Discover/call 返回可读错误，不阻断对话与技能。

## 备份与重置

```bash
# 备份
cp ~/.personal-super-assistant/assistant.db ./assistant.db.bak

# 重置（丢失会话、记忆、审计等）
rm ~/.personal-super-assistant/assistant.db
# 再次启动应用即可重建空库并重新插入预置专家/MCP
```

## 注意事项

1. **不要**把含真实 API Key 的 `assistant.db` 打进交付 ZIP。  
2. FTS5 虚拟表随 schema 创建；手工改基表后需同步维护 FTS 与触发器。  
3. 三端共用同一 schema；路径分隔由应用层 `pathlib` 处理。  
4. 知识索引失败（如 PDF 无文本层）会在文档状态中体现，而不是写空切片充数。
