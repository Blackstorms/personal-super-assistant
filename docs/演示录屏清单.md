# 演示录屏清单

大赛要求：高清、无加速剪辑、无黑屏卡顿、MP4、无水印、无加密，放入交付压缩包**根目录**（建议文件名 `演示录屏.mp4`）。若评委环境无法部署，将以本录屏 + 源码作为功能验收依据；残缺或与代码不符直接扣分。

建议分辨率 ≥1080p，系统音可关，操作时配合简短口述（赛题层级：必做 / 进阶 / 创新）。可分段拍摄后按时间轴拼接，但**不要倍速、不要删掉失败重试**（失败应换成一次成功路径）。

## 必须覆盖的操作顺序

### A. 启动与必做

1. **启动**：运行 `install.sh` 片段或直接打开桌面端；登录页默认 `admin / admin`；侧栏健康绿点。  
2. **LLM**：设置 → 模型 → 新增/编辑 → 探测连通性 → 设为默认（密钥只显示掩码）。  
3. **白名单**：新建任务 →「打开本地文件夹」，选一个含文本文件的目录（同步写入白名单并建文件夹空间）。  
4. **关于**：设置 → 关于，展示 health（含 Hermes available）与「重试连接 / 重启后端」。  
5. **内置技能**：插件市场 → 技能，展示不少于 3 个内置技能（建议 `file-summarize`、`todo-draft`、`text-organize`），执行一次「试运行」。

### B. 进阶

6. **专家**：插件市场 → 专家，打开一个预置专家或新建人设并保存。  
7. **连接器**：插件市场 → 连接器，打开预置「飞书」或「文件系统」，填最小配置（filesystem 可用本机路径）；测试 / Discover；勾选工具过滤并保存重载。  
8. **技能斜杠 / Hub**：技能页看 Bundle 或 Hub 搜索（有网络时）；回到对话输入 `/file-summarize`，观察斜杠菜单与工具/技能指引。  
9. **Hermes 工具组**：设置 → Hermes 工具组，启停一项；对照关于页 `hermes.available`。  
10. **对话体验**：新建任务，选择模型/专家/资料库（可空），发送消息，展示 SSE 流式、思考区（若有）、停止按钮、上下文用量。需要时附加一个本地文件。  
11. **联网搜索**：问一个时事/需检索的问题，展示 `web_search` 工具卡片。  
12. **确认闸**：让助手写入白名单内一个文件，展示确认条，先拒绝再重试确认（或两次对话分别演示）。  
13. **记忆（对话内）**：同一项目开两个会话各说一句偏好；第三个会话提问，观察是否带上项目上下文（可口述「后台有 session_summary」）。长对话可额外展示压缩标记。  
14. **办公 IM（可选但建议）**：飞书连接器已填凭证时，让助手发一条测试消息或查用户；无凭证则停留在连接器配置页，说明预置企微/飞书入口。

### C. 创新

15. **项目**：项目页创建项目，填写指令并绑定专家/技能，从项目内开任务。  
16. **侧栏工作空间**：底部「空间 / 任务」切换，点开最近会话。  
17. **资料库**：新建知识库 → 快速添加文件或文件夹 → 库内检索 → 对话勾选该库提问。  
18. **审计舱**：打开列表，按工具名筛选，回放入参/结果/耗时，导出 Markdown。  
19. **清单**：从带「待办」的助手回复生成清单，勾选一项，进入详情，可选导出 Markdown。  
20. **自动化**：用模板或对话创建定时任务（建议「几分钟后」一次性），展示列表中的下次运行时间；若能等到一次运行记录更好。

### D. 异常与容错

21. **异常**：关闭后端或用错误 Key 发消息，展示可读错误条，再点「重试连接 / 重启后端」恢复。  
22. **白名单拒绝**：对未授权路径读文件，展示失败/403 类提示（对话或审计中均可）。

## 验收自检

- [ ] 画面清晰、操作连贯、无倍速  
- [ ] 必做四项均出现：启动健康、LLM、白名单文件夹、技能试运行  
- [ ] 进阶：MCP 或技能斜杠、流式对话、确认闸至少各一次  
- [ ] 创新：项目或资料库、审计、清单至少各一次  
- [ ] 与当前源码 UI 文案一致（插件市场 / 自动化 / 资料库，而不是旧版「记忆中心」独立页）  
- [ ] 文件为 MP4，位于 ZIP 根目录
