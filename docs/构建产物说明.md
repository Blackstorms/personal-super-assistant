# 可运行构建产物说明

大赛要求：除源码外单独提交编译后的可运行产物，保证**无需二次编译**即可启动，作为稳定性评分依据。

本项目产物分两层：**后端 sidecar**（PyInstaller）打进 Electron `extraResources`；**桌面安装包**（electron-builder）给评委双击安装。构建步骤见 [`三端打包说明.md`](./三端打包说明.md)。

## 1. 交付时请放入压缩包的文件

建议目录：`{参赛编码}-个人超级助理/release/`。

| 平台 | 产物 | 说明 |
|------|------|------|
| Windows x64 | `PersonalSuperAssistant Setup x.x.x.exe` | NSIS 安装包；或 `win-unpacked/` 免安装目录 |
| macOS Intel | `PersonalSuperAssistant-x.x.x-x64.dmg` | 或 `.app` |
| macOS ARM | `PersonalSuperAssistant-x.x.x-arm64.dmg` | Apple Silicon |

版本号与 `apps/desktop/package.json` 的 `"version"` 一致（当前 `1.0.0`）。

若安装包体积过大，至少提交**录屏所用机器对应架构**的一份完整包，并在项目说明中写明其余架构的构建命令，避免被理解为「宣称三端却无产物」。

## 2. 后端 sidecar（可随安装包内置，也可单独列出）

构建输出约定：

```text
resources/sidecars/win32-x64/server-win-x64.exe
resources/sidecars/darwin-x64/server-darwin-x64
resources/sidecars/darwin-arm64/server-darwin-arm64
```

Electron 打包时 `extraResources` 会把对应目录拷进应用包的 `sidecars/`。Main 按 `process.platform` + `process.arch` 解析可执行文件。sidecar **包含** vendored Hermes 与内置 `skills/`，安装后可离线使用技能/MCP toolsets。

开发验证**不强制**预构建产物：

```bash
# 后端
cd server && source .venv/bin/activate
uvicorn app.main:app --host 127.0.0.1 --port 18765

# 桌面
cd apps/desktop && npm run electron:dev
```

## 3. 评委如何运行构建产物

1. 安装 exe / 打开 dmg 将应用拖入「应用程序」。  
2. 首次启动会在用户目录创建 `~/.personal-super-assistant/` 并建 SQLite。  
3. 使用 `admin` / `admin` 登录（如构建时未改环境变量）。  
4. 在设置中填写评委自己的 LLM `base_url` 与 API Key（交付包内不应带真实密钥）。  
5. 侧栏绿点亮起后即可按录屏路径操作。

macOS 若提示未签名，需在「隐私与安全性」中允许，或右键打开。Windows 智能屏幕可能拦截未签名 NSIS，选择仍要运行即可。

## 4. 不要放进产物目录的内容

- `server/.venv`、`node_modules`、PyInstaller `build/` 中间目录  
- 含 API Key 的 `.env` 与 `assistant.db`  
- 未压缩的 Hermes 完整 git 历史（源码树 `third_party/hermes-agent/` 随源码提交即可，sidecar 已打包运行时需要的部分）
