# 前端界面设计

指导生成或改版前端界面时：
1. **先定方向**：明确品牌气质（字体、色板、动效密度），写入 CSS 变量
2. **第一屏**：品牌/产品名是主信号；一个标题、一句说明、一组 CTA、一个主视觉
3. **避免**：紫渐变白底、暖米色+衬线+陶土色、报纸风密排、纯扁平单色无层次
4. **卡片慎用**：非交互容器尽量不要卡片；Hero 禁止浮层徽章/贴纸
5. **动效**：至少 2–3 处有意图的动效（进入、悬停、焦点），忌噪声
6. 交付时给出：布局说明 → 关键组件结构 → 可落地的样式要点
