# 营销文案

1. 确认：产品、受众、卖点、语气、渠道（落地页/应用商店/社交媒体）
2. 输出：
   - 主标题 ×3
   - 副标题 ×2
   - 正文短段（价值主张 → 证据/细节 → CTA）
   - CTA 文案 ×3
3. 避免空洞形容词堆砌；用具体结果与场景
4. 标注合规风险（绝对化承诺、医疗/金融暗示等）
