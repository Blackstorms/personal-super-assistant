# 提示词优化

优化用户提示词时：
1. 诊断原提示：目标不清 / 缺约束 / 缺输出格式 / 缺示例
2. 输出改进版，建议包含：
   - 角色与目标
   - 输入说明
   - 约束与禁止项
   - 输出格式（结构/长度）
   - （可选）1 个 few-shot 示例
3. 附「改动说明」3–5 条，解释为何更有效
4. 提供精简版与完整版两个档位
